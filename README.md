# 轻耳（QingEr Transcriber）

专为小米手机（arm64-v8a，适配小米 14 / 小米 17 等澎湃 OS 机型）打造的**零广告、纯开源**音视频转录工具，支持在线与本地双引擎一键切换。

## 核心能力
- **应用内实时录音 + 边录边转（v1.3 新增）**：应用内直接录音（16kHz 单声道），约 60 秒一段边录边转，实时出带时间戳的文稿；复用在线优先、断网回退离线的引擎策略；录音和识别分开，断网时分段排队、之后补转；来电自动暂停。体验参考 OPPO AI 心力球（9.8 克夹子式可穿戴录音器：早上拿出收纳盒自动记录、晚上放回自动停止、AI 键标记重点、自动生成今日结构化摘要；目前只配合 OPPO/一加/真我手机使用，小米手机用不了原品，故在 App 内复刻同款体验）。
- **重点标记（v1.3 新增）**：录音过程中点一下「标记重点」，给当前时间点打个标记（对应心力球机身 AI 键短按），标记会出现在文稿时间线里，回顾时一眼能找到。
- **蓝牙耳机录音（v1.3 新增）**：蓝牙耳机已连接时自动走蓝牙 SCO 录音，否则用手机麦克风；界面显示当前麦克风来源；需要蓝牙权限（仅用于检测已连接的耳机）。蓝牙 SCO 音频为窄带，App 内重采样到 16kHz 后再转写。
- **AI 日分析（v1.3 新增）**：用同一个 Groq API Key 调 `openai/gpt-oss-120b`（免费 tier：30 请求/分钟、每天 1000 次请求、8000 tokens/分钟），对当天文稿生成结构化摘要：重要观点、待办事项、做出的决定、值得记住的事；输出 Markdown，App 内保存、可查看、可分享。长文稿自动分段摘要再合并。
- **隐私选项（v1.3 新增）**：可开启「转写后删除原录音（只留文字）」，默认关闭（借鉴心力球“只留文字、不留原音”）：开启后录音转写全部完成后自动删除原录音文件，只保留文稿和分析。
- **待补转更清晰（v1.3.2）**：录完直接在主界面看到待补转分段，每条带醒目的「补转」按钮，不用再点进录音列表；录音列表里的条目也明确标出可点击。打开 App 时自动补转待补转分段（仅在线模式、未录音、已填 Key 时，每个录音每打开一次最多自动补转一次；失败保留待补转状态，可手动补转）。
- **小红书短链（v1.3.2）**：支持 `xhslink.cn` 短链解析（之前只认 `xhslink.com`）；小红书页面受限（登录墙/风控）时明确提示保存视频到相册再用本地文件转录。
- **总结做大（v1.3.2）**：主界面直接展示今日总结内容，今日/本周/本月三个按钮；打开 App 时自动生成今日总结（已有则不重复生成，失败只留提示不打扰）；本周总结汇总过去 7 天、本月总结汇总本月 1 号至今，结构为本周/本月重点 + 重要观点、待办事项、做出的决定、值得记住的事。
- **v1.3 新增权限说明**：录音（RECORD_AUDIO）、蓝牙连接（BLUETOOTH_CONNECT，仅检测耳机）、前台服务麦克风类型（FOREGROUND_SERVICE_MICROPHONE）、读取电话状态（READ_PHONE_STATE，仅用于来电自动暂停，可拒绝）、音频模式设置（MODIFY_AUDIO_SETTINGS，普通权限，用于蓝牙录音时切换音频模式）。
- **在线极速模式（v1.2 起改用 Groq，默认）**：接 Groq 免费 Whisper 接口（`whisper-large-v3-turbo`），速度比本地离线快很多，无需下载 228 MB 模型；免费额度每天 8 小时音频（注册只需邮箱或 Google 账号，无需实名）；按约 3 分钟静音点自动分段上传，实时输出带 `[HH:MM:SS]` 时间戳的文稿。额度用完或断网时自动回退本地离线，也可一键手动切换。
- **本地离线模式**：基于 [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) + 阿里开源 [SenseVoiceSmall](https://github.com/FunAudioLLM/SenseVoice)（int8 量化版，自动识别中英粤日韩并自动加标点），音频不出手机，永久免费。
- **多源一键导入**：支持直接粘贴或系统分享 **小宇宙单集链接**、**B 站视频链接（含 `b23.tv`）**、**小红书笔记链接（含 `xhslink.com` / `xhslink.cn` 短链与分享口令，仅视频笔记）**、**播客 RSS/音频直链**，以及选取手机本地音视频文件。
- **国内高速下载模型**：首次打开点一次「一键下载离线模型」，自动优先从魔搭社区（ModelScope）拉取约 228 MB 模型文件，之后永久离线运行。
- **后台保活与导出**：内置前台服务与 WakeLock，支持锁屏转写超长播客，自动生成带时间戳的 Markdown 文稿并支持一键复制或导出分享。
